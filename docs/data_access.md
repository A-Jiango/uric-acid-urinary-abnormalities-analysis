# Data Access

The source data are not distributed with this repository.

The analysis requires an authorized local workbook supplied through the `ANALYSIS_WORKBOOK` environment variable. Source-column labels are provided through a local column map.

Generated outputs are written to `outputs/` by default. The directory is ignored by Git.

The analysis code is public, but the underlying health-examination records are not publicly available because they contain institution-based clinical information and are subject to institutional data-access restrictions.
